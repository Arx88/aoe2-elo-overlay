# Estudios y estado de las decisiones

Revisión de producto: 14–15 de noviembre de 2026. Los estudios describen evidencia disponible, auditoría del modelo inicial y propuestas. Un hallazgo de auditoría no demuestra que el problema siga presente después de las correcciones; una fórmula propuesta no implica que exista una fuente de datos conectada.

La dependencia común de las métricas profundas es un extractor de estado reproducible y validado. La comparación «mejor que X % de usuarios» necesita además un dataset autorizado de otros jugadores, definiciones compatibles y cohortes verificadas por versión/contexto/nivel. El historial propio permite una comparación personal con su muestra visible, sin convertirla en ranking poblacional.
